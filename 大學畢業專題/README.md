# 腳底壓力辨識與機器學習

用 40 個壓力感測器量到的腳底壓力,辨識「這是 15 位受試者中的哪一位」,並比較五種機器學習演算法的**準確度**與**訓練時間**:SVM、隨機森林(RF)、Gradient Boosting(GB)、kNN、XGBoost。

完整的研究動機、文獻與方法見 [專題期末報告](專題期末報告.pdf)。**報告中的準確度數字有誤,請先看[更正說明](#更正說明)。**

## 做了什麼

- **資料:** 15 位受試者,左右腳各走過感測平台 20 次。平台上有 10 × 4 共 40 個感測器,每次走過以 25 fps 記錄,原始資料共 15000 筆。資料來源見[資料集](#資料集)。
- **兩種資料形式:** 原始資料(每幀一筆),以及把每次走過的 25 幀取平均後的平均資料(600 筆)。
- **額外特徵:** 從感測器有無讀數推得的腳掌**長、寬**,以及壓力**重心**座標,用來觀察多加特徵有沒有幫助。
- **切分方式:** 每位受試者、每隻腳,前 16 次走過的資料訓練,後 4 次測試。

## 結果

以下是畢業後重新執行 [`experiment.py`](程式碼/experiment.py) 的結果(隨機演算法各跑 3 次取平均;macOS、Python 3.12、scikit-learn 1.9、XGBoost 3.4)。

**平均資料**(訓練 480 筆 / 測試 120 筆):

| 演算法 | 準確度 | 訓練時間 |
|---|---|---|
| SVM(linear) | 73.3% | 0.019 秒 |
| **RF** | **86.7%** | 0.109 秒 |
| GB | 77.2% | 2.915 秒 |
| kNN | 54.2% | 0.001 秒 |
| XGBoost | 81.7% | 1.049 秒 |

**原始資料**(訓練 12002 筆 / 測試 2998 筆,只比較三種集成式演算法):

| 演算法 | 準確度 | 訓練時間 |
|---|---|---|
| RF | 75.8% | 1.686 秒 |
| GB | 75.1% | 51.063 秒 |
| XGBoost | 78.0% | 3.235 秒 |

**額外特徵的影響**(準確度):

| | SVM | RF | GB | kNN | XGBoost |
|---|---|---|---|---|---|
| 平均資料 | 73.3% | 86.7% | 77.2% | 54.2% | 81.7% |
| + 重心 | 73.3% | 88.6% | 76.1% | 54.2% | 82.5% |
| + 重心 + 長寬 | 73.3% | 85.6% | 76.4% | 54.2% | 81.7% |

**結論:**

- 集成式演算法(RF、XGBoost、GB)的準確度都高於 SVM 和 kNN。
- 平均資料上 RF 最準,而且訓練時間只有 GB 的約 1/25、XGBoost 的約 1/10,是準確度與速度兼顧的選擇。
- 原始資料的表現沒有比平均資料好;在原始資料上,XGBoost 準確度最高,訓練時間約為 GB 的 1/15。
- 加入重心、長寬**沒有明顯幫助**。
- 測試集只有 120 筆(每筆約 0.8 個百分點),準確度差在 2\~3 個百分點內的演算法不能說有差別。

## 更正說明

專題報告(與當時的簡報)中 RF、GB、XGBoost 的準確度是 96\~100%(例如 XGBoost 100%)。畢業後我重新整理這份專題時發現,**這些數字是錯的**:當年的實驗程式([`avg.py`](程式碼/舊版實驗/avg.py))把要預測的答案(受試者編號 `ID`)也放進了特徵欄位,模型等於直接拿到答案。

我用同一份資料、同樣的切分,只改變「特徵裡有沒有受試者編號」,結果如下:

| 資料 | 特徵 | RF | GB | XGBoost |
|---|---|---|---|---|
| 平均資料 | 40 個感測器 | 86.7% | 77.2% | 81.7% |
| 平均資料 | 40 個感測器 + 編號(當年的寫法) | 97.8% | 97.5% | 100% |
| 原始資料 | 40 個感測器 | 75.8% | 75.1% | 78.0% |
| 原始資料 | 40 個感測器 + 編號(當年的寫法) | 96.7% | 100% | 100% |

含編號的結果與報告的數字吻合(報告:平均資料 RF 96.7%、GB 98.3%、XGBoost 100%;原始資料 RF 97.2%、GB 100%、XGBoost 100%)。最終回簡報的「修正實驗」頁也可以看到:「舊」的 RF 83\~84%、GB 76\~78%,與上面誠實設定的結果相近;「新」的 96\~98% 則與含編號的結果相近。

SVM 和 kNN 在含不含編號時的準確度完全相同,推測是編號的數值(1\~15)遠小於感測器讀數(可達數千),對它們的距離計算幾乎沒有影響,所以這兩個演算法的數字不受這個問題影響。

**受影響的部分:** 報告第四章中 RF、GB、XGBoost 的準確度(圖 10、圖 12、圖 13),以及結論中「XGBoost 準確度 100%」。**不受影響的部分:** 系統架構、特徵定義、資料與方法,以及「RF 與 XGBoost 優於 SVM、kNN」的大方向。報告 PDF 與簡報保留當年的原貌,未做修改;正確的數字以本頁為準。

`GradientBoosting.py`、`RandomForest.py`、`SVM.py`、`kNN.py` 與 `avg.py` 是當年的實驗原稿,放在 [`程式碼/舊版實驗/`](程式碼/舊版實驗) 供對照。它們的檔案路徑寫死成當年的資料夾,而且部分讀取的檔案已不在這個 repo 裡,現在無法直接執行。

## 如何重現

在 Python 3.12 測試過:

```sh
cd 大學畢業專題
pip install -r requirements.txt
python 程式碼/experiment.py
```

約 3 分鐘,輸出上面所有表格(準確度固定,訓練時間會因機器而異)。最後兩組是「特徵誤含編號」的對照實驗,用來示範洩漏的效果。

## 資料集

資料由實驗室學長使用 Arduino 與感測平台,找 15 位受試者實際蒐集,並在陳建翰的碩士論文中使用(見參考資料)。受試者只有編號。

| 檔案 | 內容 |
|---|---|
| [`allavg.csv`](資料集/allavg.csv) | 平均資料,600 筆(15 人 × 左右腳 × 20 次) |
| [`avggr.csv`](資料集/avggr.csv) | 平均資料 + 重心(`gx`、`gy`) |
| [`avglwgr.csv`](資料集/avglwgr.csv) | 平均資料 + 長寬(`len`、`wid`)+ 重心 |
| [`allpre-25fps.csv`](資料集/allpre-25fps.csv) | 原始資料,15000 筆(每次走過 25 幀) |

主要欄位:`ID` / `NUM` 是受試者編號(1\~15,即要預測的類別);`LERI` 是左腳(1)或右腳(2);`Order` 在平均資料中是第幾次走過(1\~20),在原始資料中則是第幾幀(1\~25),原始資料的第幾次走過是 `FREQ`;`fsr1`\~`fsr40` 是 40 個感測器的壓力值。`NO` 是流水號,`time` 實驗未使用。原始資料有少數瑕疵(部分受試者的列數是 485\~515 而不是 500,另有一列 `FREQ` 為 22),不影響實驗。
