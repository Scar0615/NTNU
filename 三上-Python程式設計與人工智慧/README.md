## 專題

### 期末:用神經網路學乘法([`專題/final_project.ipynb`](專題/final_project.ipynb))

想讓電腦學會算乘法,而不是靠內建的乘法指令。做法是先把「九九乘法表」轉成二進位 tensor 訓練一個多層感知器(MLP),再用**直式乘法**的概念把結果組合起來:

- **模型只負責一位數 × 一位數。** 輸入是兩個 4 位元的數字(共 8 個輸入節點),輸出是 7 位元的乘積(0 到 81)。網路為 8 → 64 → 16 → 7,sigmoid 啟動函數,MSE 損失搭配 Adam 訓練 10001 個 epoch,訓練好的權重存在 [`multiplier.model`](專題/multiplier.model)。
- **多位數由直式乘法組合。** 輸入兩個任意位數的整數後,程式把它們拆成一位數,每一組交給模型算,再依位值移位、加總,並和正確答案比對。

我重新載入 `multiplier.model` 驗證:100 題一位數乘法全部答對;`123 × 456`、`987654321 × 975318642059` 都算對;隨機抽 1000 組最多 6 位數的乘法也全部答對。(訓練資料就是九九乘法表本身,所以這是「學會這張表」,而不是泛化到沒看過的資料。)簡報見 [`期末報告.pptx`](專題/期末報告.pptx)。

### 期中:Dcard 文章分析([`專題/mid_project.py`](專題/mid_project.py))

想知道大家在 Dcard 上貼文的主題大致是什麼、哪些主題比較熱門。Dcard 是動態載入的頁面,所以用 **Selenium** 自動操作:在終端機輸入關鍵字與下拉次數後,程式自動搜尋、模擬按下「下方向鍵」載入更多文章,擷取每篇文章的分類、標題、表情數與留言數,最後統計各分類的貼文數並依數量排序。簡報見 [`期中報告.pptx`](專題/期中報告.pptx)。
