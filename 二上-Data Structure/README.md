# 資料結構

用 C 語言實作課堂上的基本資料結構與演算法。這裡收錄 4 次較完整的作業,每次作業都附有使用說明 PDF(輸入格式、功能與錯誤訊息)。

| 作業 | 做了什麼 | 用到的資料結構 / 演算法 |
|---|---|---|
| [`HW3`](HW3) | **矩陣運算程式。** 可以儲存多個具名矩陣,並提供顯示、取子矩陣、轉置、兩矩陣相加、矩陣的 k 次方六項功能 | 結構(`struct`)、稀疏矩陣(三元組)表示法,說明中標示各功能的時間複雜度 |
| [`HW6`](HW6) | **中序運算式計算機。** 輸入含括號的四則運算式,轉成後序式後計算結果;能辨識 12 種格式錯誤(例如「運算子後面接運算子」、「括號未配對」)並印出對應的錯誤訊息 | 堆疊、中序轉後序 |
| [`HW8`](HW8) | **商品管理系統。** 從檔案載入商品,支援搜尋、進貨、刪除、出貨、依編號排序列出、修改編號、找出最高價商品,結束時存回檔案 | 二元搜尋樹(新增、搜尋、刪除、中序走訪)、檔案讀寫 |
| [`HW11`](HW11) | **旅行的最少過路費。** 給定城市、公路與各州政府,由其他州政府管轄的公路費用要乘上倍率,求依序走訪指定城市所需的最少過路費 | 圖、Dijkstra 最短路徑 |

## 編譯與執行

```sh
gcc HW3/40847016S.c -o hw3 && ./hw3
gcc HW8/dsahw8.c -o hw8 && ./hw8
gcc HW11/dsahw11.c -o hw11 && ./hw11
```

`HW6` 使用了 Windows 專用的 `conio.h`(`getch()`),需要在 Windows 上編譯。

`HW11` 沒有提示訊息,直接輸入資料即可,輸入格式見 [`HW11/hw11.pdf`](HW11/hw11.pdf)。例如說明中的範例輸入會得到 `Least Fee is 6`。
