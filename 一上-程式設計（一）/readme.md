# 程式設計（一）

C 語言入門課,從基本語法一路練到遞迴、指標與函式指標。

教授每次作業約出 5 題,每一題是一支獨立的小程式。每份作業除了程式,還要附上 `Makefile`(助教只要輸入 `make` 就能一次編譯全部程式)和 readme(說明每支程式的用途與用法,見各資料夾的 `readme.pdf`)。期中考、期末考採同樣的形式,只是不用寫 readme,改為撰寫對教授的回饋。作業與考試的份量偏重,但把 C 語言練得很扎實。

## 內容

| 資料夾 | 做了什麼 |
|---|---|
| `hw01` | 基礎輸入輸出:印出個人資訊、5 位數各位數相加、由兩點求直線方程式並代入求 y;探討 `printf()` 的回傳值,並整理 `stdio.h` 的位置與 gcc 常用編譯選項(`-ansi`、`-std=c99`、`-Wall`、`-Werror` 等) |
| `hw02` | 條件判斷:三角形銳角/直角/鈍角判斷、計程車車資(里程、停等秒數、夜間與農曆新年加成)、有限狀態機、21 點判斷、撲克牌五張牌型(9 種組合);探討 `scanf()` 的回傳值 |
| `hw03` | 迴圈:用 k 項近似 e、巴斯卡三角形、存款複利(含利率波動的最大/最小值)、1 到 5000 萬之間的完全數、數位相加至個位數 |
| `hw04` | 遞迴與函式:河內塔(遞迴版與迴圈版)、多項式微分、文字編輯器的取消/復原(最多記 10 個動作)、線性迴歸、模反元素;開始把函式拆到 `.c` / `.h` 檔 |
| `hw05` | 陣列與模組化:整數矩陣加減乘、多元一次聯立方程式、麻將胡牌判斷(34 種牌)、0\~9 跑馬燈、分數四則運算並自動約分 |
| `hw06` | 指標與函式指標:四位玩家的隨機發牌,並用函式指標切換三種排序方式(A 最小、大老二、依花色);有限狀態機、座標旋轉、大數乘法;探討 `printf()` 的緩衝區行為 |

## 編譯與執行

每個作業資料夾都可以直接編譯:

```sh
cd hw02
make            # 編譯該資料夾內全部程式
./hw0201        # 執行其中一支
make clean
```

各程式的輸入格式請看該資料夾的 `readme.pdf`。

期中考、期末考的程式檔沒有保留,所以這裡只有作業。
