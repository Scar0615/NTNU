# 程式設計（二）

這堂課以 C 語言為主,重點是**檔案與二進位格式處理、命令列工具、動態記憶體,以及把程式整理成可維護的專案**。

每次作業約 5 題,每一題是一支獨立的小程式。每份作業都附上 `Makefile`(助教只要輸入 `make` 就能一次編譯全部程式)和 readme(說明每支程式的用途與用法)。期中考、期末考採同樣的形式,只是不用寫 readme,改為撰寫對教授的回饋。

## 內容

| 資料夾 | 做了什麼 |
|---|---|
| `hw01` | 自製字串函式庫(`mystrchr`、`mystrstr`、`mystrtok` 等七個)、IPv6 位址格式檢查、支援 `?` 與 `*` 的萬用字元比對、分數(`struct`)的四則運算與字串算式解析 |
| `hw02` | 檔案加密/解密(字母轉換表)、字幕時間軸位移、C 語法突顯(終端機上色)、`fibonacci` / `factorial` 的自動測試、設定檔(conf)修改、`int32_t` 與 `uint32_t` 位元運算的差異分析 |
| `hw03` | 英超球隊戰績分析、圖檔 16 進位輸出、依四角 RGB 產生漸層的 BMP 圖檔、遊戲存檔能力值修改器 |
| `hw04` | 實作 AWK 的部分功能(欄位擷取)、JPG 縮圖與 BMP 的互相轉換(`-w` / `-e` 選項)、BMP 資訊隱藏(可指定每個 byte 使用的位元數 `-b`)、macro 練習 |
| `hw05` | Base64 編碼/解碼(命令列選項)、每秒顯示網路 TX/RX 速度、分級的 `debug_printf` 除錯輸出 |
| `midterm` | 期中考:分數運算、BMP 檔案格式處理 |
| `final` | 期末考:BMP 檔案處理、讀取 `/proc/stat` 計算 CPU 使用率、用動態記憶體與鏈結串列儲存矩陣元素 |
| [`final-project`](final-project) | 期末專題:**Take 6!(誰是牛頭王)** 桌遊,見下方 |

## 期末專題:Take 6!

用 C 語言完整實作的 Take 6! 終端機桌遊:

- 真人可以對 1\~9 個電腦玩家(共 2\~10 人),電腦有**兩種難度**。
- 難度 2 會記牌並計算每張牌的期望罰分;對上隨機出牌的電腦,2 人局勝率約 **64%**。
- 遊戲規則、AI 與介面分成獨立的模組,附有單元測試與 AI 對戰程式。

詳細說明、編譯與遊玩方式請看 [`final-project/README.md`](final-project/README.md)。
