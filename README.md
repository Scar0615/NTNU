# 大學課程作品集

國立臺灣師範大學(NTNU)資訊工程學系。這裡收錄我在大學期間較完整的課程作業與專題,涵蓋 C 語言、資料結構、電腦圖學、機器學習、遊戲開發與系統程式。

## 資工最重要的六科

這六科裡,除了資料結構、演算法可能有比較多實際寫程式的機會,其他科都偏理論。資料結構的作業收錄在上方,其餘五科沒有放上來的原因如下:

| 課程 | 沒有收錄的原因 |
|---|---|
| 計算機結構 | 作業是觀念題,搭配期中、期末考,沒有程式實作 |
| 作業系統 | 作業是觀念題,搭配期中、期末考,沒有程式實作 |
| 線性代數 | 作業是觀念題,搭配期中、期末考,沒有程式實作 |
| 離散數學 | 作業是觀念題,搭配期中、期末考;期末專題是從教授給的題目中選一題上台講解,沒有程式實作 |
| 演算法 | 作業是在 Normal OJ 上解題(類似 CPE,助教每次出 4 題)。題目屬於系上的課程資源,所以不公開 |
