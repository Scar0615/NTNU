# 數值方法

用 Python 實作課堂上的數值方法:求根、解聯立方程式、內插、曲線擬合與最佳化。作業都是每週上課時當場完成的,期中、期末考時,老師會出題目要我們用自己當初作業寫的程式碼來計算,另外還有一些觀念題。我覺得這種考法很有意思,因為程式碼真的是自己的工具。

## 內容

| 作業 | 主題 | 做了什麼 |
|---|---|---|
| [`hw0`](hw0.py) | 浮點數運算 | 用迭代 `ans = x·ans + 1` 計算 1 + x + x² + … + x⁵⁰(x = 1.0001) |
| [`hw1`](hw1.py) | 二分法 | 求 x − ∛x − 2 = 0 的根 |
| [`hw2`](hw2.py) | 不動點迭代 | 求 x = ∛(2x + 2) 的根 |
| [`hw3`](hw3.py) | 牛頓法 | 求三個非線性方程式的根:x⁵ + x − 1 = 0、ln x + x² = 3、sin x = 6x + 5 |
| [`hw4`](hw4.py) | LU 分解 | 輸入任意多個變數的聯立方程式,以高斯消去法分解出 L、U 矩陣並解出答案 |
| [`hw5`](hw5.py) | 含列交換的 LU 分解 | 分解出 P、L、U 三個矩陣 |
| [`hw6`](hw6.py) | Jacobi 迭代法 | 用迭代解 10 個變數的線性方程組 |
| [`hw7`](hw7.py) | 多變數牛頓法 | 由圓上三個點,求圓心 (h, k) 與半徑 r |
| [`hw8`](hw8.py) | Lagrange 內插法 | 由四個資料點內插出指定位置的函數值 |
| [`hw9`](hw9.py) | Newton 差商內插法 | 建立差商表(divided differences)並內插 |
| [`hw10`](hw10.py) | 最小平方法 | 以正規方程式(AᵀA x = Aᵀb)做曲線擬合 |
| [`hw11`](hw11.py) | Gram–Schmidt 正交化 | 對一組向量做正交化,得到 QR 分解的矩陣 |
| [`hw12`](hw12.py) | 高斯–牛頓法 | 非線性最小平方:求圓心與半徑,使圓盡可能與四個給定的圓相切 |
| [`hw13`](hw13.py) | 梯度下降法 | 用固定的學習率尋找多項式的極小值 |

這些程式大多不用外部函式庫,矩陣運算、消去與迭代都是自己寫的迴圈;`hw6`、`hw10`、`hw12` 只用了 NumPy 處理矩陣的乘法與反矩陣。

```sh
pip install numpy
python hw3.py          # 直接印出結果
python hw4.py          # 依提示輸入變數個數與每一列的係數與 b
```
