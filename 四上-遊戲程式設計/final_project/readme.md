# 期末專題:ALIEN

分組製作的像素風射擊遊戲。我們分工成玩法發想組、程式組、美術組,其中程式組是我和另一位同為資工系的同學一起完成的。

## 玩法

- **操作:** 按 `W`、`A`、`S`、`D` 或方向鍵移動太空船,子彈會自動發射;躲開外星人的彈幕,擊敗 Boss。
- **生命:** 玩家有 3 條命,被彈幕擊中會扣血,歸零就 Game Over。
- **Boss:** 生命 1000,依剩餘血量分成四個階段,攻擊方式逐步升級:

| Boss 血量 | 攻擊方式 |
|---|---|
| 1000 \~ 800 | 隨機飄移,發射第一種彈幕 |
| 800 \~ 600 | 換成第二種彈幕 |
| 600 \~ 400 | Boss 退場,召喚三隻小怪(各 100 血) |
| 400 以下 | Boss 回場,兩種彈幕同時發射 |

- **勝負:** Boss 血量歸零即勝利;勝利或失敗畫面按 `P` 可回到開始畫面重玩。畫面左下角顯示分數。

## 執行

用 [Processing](https://processing.org/download)(Java 模式)開啟 `final_project.pde` 並執行。圖片素材在 `data/` 資料夾,請保持原本的目錄結構。開始畫面點擊滑鼠即可開始遊戲。
